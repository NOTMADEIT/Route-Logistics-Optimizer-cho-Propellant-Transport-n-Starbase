# Route Logistics Optimizer cho Propellant Transport n Starbase

## Giới thiệu
Dự án tối ưu hóa tuyến đường vận chuyển propellant cho Starbase.

## Tính năng chính
- Tối ưu hóa lộ trình
- Tính toán thời gian, chi phí
- Giảm thời gian delay
- Tối ưu số Tanker
- Giảm rủi ro boil-off cryogenic

## Công nghệ
- Optimization (PuLP)
- Visualization (Plotly/Streamlit)
- Simulation
